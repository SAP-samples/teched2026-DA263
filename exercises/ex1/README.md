# Exercise 1 - SAP HANA Cloud AI features

In this exercise we will use SAP HANA Cloud AI features - semantic search, LLM access, and Knowledge Graph engine - to build an **Object Index**, i.e. a searchable catalog of database objects. An AI agent can query this index to discover relevant tables and views when answering a user's question in natural language.

Prerequisite: you have connected to SAP HANA Cloud (hana-db) and opened the SQL Console in SAP HANA Cloud Central.

You can either read through the exercises' descriptions in this repository and copy the SQL statements one-by-one into the SQL console of SAP HANA Cloud Central.

**OR**

Open the complete SQL script [2026 Q3 TechEd 2026 DA263_000.sql](../../SQL/2026%20Q3%20TechEd%202026%20DA263_000.sql) for exercises 1.1 - 1.8, so you have all statements in a single SQL console window.
